# hailuo (video: MiniMax)

## Định dạng prompt
- Image-to-video. Prompt mô tả chuyển động bằng câu tự nhiên, 1–2 câu.
- Có thể dùng chỉ dẫn camera dạng ngoặc vuông nếu phiên bản hỗ trợ (ví dụ `[Push in]`, `[Pan left]`); nếu không, viết bằng lời.

## Tham chiếu
- Chế độ subject reference (tùy phiên bản) để giữ nhân vật.

## Tham số
- 9:16, 6s. Chi phí thường thấp → hợp để tạo nhiều biến thể rồi chọn.

## Lỗi thường gặp
- Chuyển động hơi nhiều → nhấn `subtle, minimal motion, calm`.
